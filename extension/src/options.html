GroveVault settings

Pair with Grove Vault
In the Grove Vault app: Settings → Browser extension → Pair the extension. Type the code it shows here.
How it stays safe
The extension only talks to the Grove Vault app on this phone (127.0.0.1), and everything is encrypted with your pairing code. A website only ever gets the logins saved for that website, and only when Grove Vault is unlocked.
